## 2.0.0.RC1

Требуется миграция:

- Телеметрия стандартизирована во всех модулях (HTTP клиент и сервер, база данных, gRPC, Kafka, кэш, SOAP, JMS, планировщик, Camunda, Zeebe, Resilient) — ключи конфигурации, метрики и трассировка приведены к единым соглашениям
- SOAP клиент переведён на `CXF 4.2.2` с поддержкой только Jakarta
- Модуль Netty переработан с поддержкой транспорта `io_uring` (`URING`)
- Опция `interceptors` генератора OpenAPI заменена опцией `extensions`
- `RapiDoc` в OpenAPI заменён на `Scalar` (с кэшированием ответов)
- Контракты Resilient усилены и упрощены

Добавлено:

- Добавлена поддержка модулей на основе классов через `@FactoryModule` и `Tag.Factory`
- Добавлены фабричные модули для компонентов сервера, клиента, базы данных, Redis, S3, Flyway и Liquibase
- Добавлена поддержка `@DefaultComponent` для классов `@Component`
- Добавлены метрики `RateLimiter` в модуле Resilient и продвинутые реализации `CircuitBreaker`
- Добавлена поддержка `KoraRetryBudget`, `jitter` и `backoff` для `@Retry`
- Добавлен модуль HTTP Client `Apache`
- Добавлено типизированное сопоставление ответа HTTP клиента `Either<T, E>`
- Добавлена обёртка `KoraTracer` с режимами parent, root и linked span
- Добавлена поддержка `CRON` в JDK планировщике
- Добавлено маскирование структурированных JSON логов со сгенерированными метаданными
- Добавлены новые аннотации валидации и валидаторы по умолчанию, а также валидация конфигурации для мапперов и источников
- Добавлены значения по умолчанию для JSON дискриминатора с обратной совместимостью при отсутствии поля
- Добавлены макросы базы данных: type use для `@Column`, макросы аргументов метода, алиасы и маппинг one-to-many
- Добавлена опция `extensions` генератора OpenAPI как преемник `interceptors`
- Добавлены режимы безопасности OpenAPI с анонимным доступом
- Добавлен единый путь `clientConfig` как поведение по умолчанию и общий интерфейс клиента для одной модели с разными статус-кодами
- Добавлены асинхронные режимы кэша с общим executor и конфигурация включения кэша с no-op поведением при отключении
- Добавлена телеметрия кэша `Caffeine` с контрактами, согласованными с Redis, и контракты `RedisCache#putExpireAfterWrite`
- Добавлен модуль S3 AWS клиента
- Обновлён `Swagger UI` с поддержкой страницы редиректа `OAuth2`
- Добавлено отслеживание `#include` файлов `HOCON` в `ConfigWatcher`
- Добавлено установление соединения gRPC `ManagedChannel` при инициализации

Улучшено:

- Улучшено сопоставление маршрутов HTTP сервера производительной гибридной реализацией
- Оптимизирована обработка заголовков HTTP и параметров сервера
- Улучшена диагностика DI с понятными подсказками ошибок AP и KSP
- Обогащены сообщения исключений времени выполнения и JUnit
- Улучшены no-op метрики телеметрии с общим реестром без аллокаций
- Усилено управление зависимостями и `kora-bom`
- Усилена конфигурация GraalVM native-image по модулям

Исправлено:

- Исправлена регистрация сгенерированных AOP прокси с супертипом в графе
- Исправлена генерация AOP прокси для no-op аспектов методов и AOP родительских интерфейсов для HTTP клиента и репозитория
- Исправлены зарезервированные слова генератора OpenAPI для каждого целевого языка и послабления для Kotlin
- Исправлен NPE генератора OpenAPI для nullable аннотации `Valid` и восстановлена фабрика `fromValue` для enum
- Исправлена обработка multipart `byte`/файлов и опция `nameMapping` в генераторе OpenAPI
- Исправлены теги безопасности OpenAPI с именами на основе схемы для Java и Kotlin клиентов и серверов
- Исправлены экстракторы значений конфигурации для интерфейсов с default методами и зависимость config watcher
- Исправлены многочисленные регистрации рефлексии для GraalVM native-image (Undertow, JDBC, Kafka, gRPC, Caffeine, Micrometer)
- Исправлен ряд проблем, портированных из ветки `1.2.x` (Kafka, Cassandra, HTTP, кэш, логирование, JUnit)
