# Блог Kora

Статьи о фреймворке Kora, его устройстве, практической серверной разработке, интеграциях, производительности и эксплуатации JVM-сервисов в продакшене.

Блог общий для всех версий документации. Статьи описывают идеи и практики, применимые к разным версиям Kora; если материал зависит от конкретного релиза, это будет указано явно.

  HTTP и Java/Kotlin, которые уже есть у сильных JVM-инженеров.
